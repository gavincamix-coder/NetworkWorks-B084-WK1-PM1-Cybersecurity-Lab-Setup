# Setting Up Kali Linux on VirtualBox 🐉

##  Project Overview

This was my first hands on project in my cybersecurity and networking journey. I set up **Kali Linux inside Oracle VirtualBox**, configured the network by assigning IP addresses, and tested the connection to make sure everything was working successfully.

As someone learning more about IT and cybersecurity, I wanted to move beyond theory and gain practical experience working with a Linux environment and virtual machines.

Although this was a beginner project, it gave me a better understanding of how virtual machines work and how network configuration helps devices communicate.

##  Project Objectives

- Install and set up Kali Linux in Oracle VirtualBox.
- Understand the basics of virtualization.
- Configure IP addresses for network connectivity.
- Verify that the network connection was working.
- Gain practical experience with a Linux operating system commonly used in cybersecurity.

##  Tools and Technologies Used

- **Kali Linux** — A Linux distribution designed for cybersecurity, penetration testing, and security research.
- **Oracle VirtualBox** — Virtualization software used to run Kali Linux in a virtual machine.
- **Networking fundamentals** — IP addressing and network connectivity testing.

##  What I Did

### 1. Set Up the Virtual Machine
Installed Oracle VirtualBox and created a virtual machine to run Kali Linux in an isolated environment on my computer.

### 2. Installed Kali Linux
Configured the virtual machine and completed the Kali Linux installation to create a working Linux environment.

### 3. Configured IP Addresses
Assigned IP addresses to configure the virtual machine's network connection and put my understanding of IP addressing into practice.

### 4. Tested Network Connectivity
Checked the network connection and confirmed that connectivity was working successfully.

### 5. Verified the Setup
Confirmed that Kali Linux was running and that the network configuration allowed the expected connection to work.
